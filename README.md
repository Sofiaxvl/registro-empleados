# Registro de Empleados

Sistema de escritorio en Java (Swing) conectado a MySQL de XAMPP mediante JDBC.
Permite gestionar empleados con el CRUD completo: crear, listar, actualizar y eliminar.

## Problemática
Sin un sistema organizado es difícil llevar el seguimiento de las actividades y mantener la información ordenada.

## Solución
Un sistema informático desarrollado en Java con NetBeans, con interfaz gráfica sencilla, que permite registrar, consultar, modificar y eliminar empleados guardándolos en una base de datos.

## Tecnologías
- Java y Swing (interfaz gráfica)
- NetBeans
- XAMPP (MySQL y phpMyAdmin)
- JDBC (mysql-connector-j 8.4.0)
- Git y GitHub

## Cómo ejecutarlo
1. Abrir XAMPP y encender MySQL y Apache.
2. En phpMyAdmin, ejecutar el script `database/registro_empleados.sql`.
3. Abrir el proyecto en NetBeans y agregar el driver mysql-connector-j en Libraries.
4. Ejecutar la clase `VentanaEmpleados`.
